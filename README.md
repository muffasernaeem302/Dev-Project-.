## 📌 Overview

**Tip Calculator** is a lightweight browser-based application developed using **HTML, CSS, and vanilla JavaScript**.

The purpose of the project is to provide a straightforward interface for calculating the appropriate tip based on a user's bill and selected tip percentage.

This project was developed as an assessment submission for **DEVWEEKENDS**, with a focus on applying fundamental frontend development concepts to a functional interactive webpage.

---

## ✨ Features

* 🧮 Calculate tips based on the entered bill amount
* 💰 Determine the resulting total amount
* 📊 Support for different tip percentages
* ⚡ Instant calculations through JavaScript
* 🎨 Clean and simple user interface
* 🖥️ Browser-based application
* 📱 Designed with responsive web development principles
* 🚫 No external frameworks required

## 🚀 Getting Started

### Prerequisites

No special software or backend server is required.

You only need:

* A modern web browser
* A text/code editor such as VS Code
* The project files

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/muffasernaeem302/Dev-Project-.git
```

Navigate into the project directory:

```bash
cd Dev-Project-.
```

Extract:

```text
project dev.rar
```

using **WinRAR**, **7-Zip**, or another archive utility.

---

## ▶️ Run the Application

After extracting the project:

1. Locate the main HTML file.
2. Open `index.html` in your browser.

Or, for a better development experience, open the project in **Visual Studio Code** and use the **Live Server** extension.

## 🧪 Example Calculation

Suppose the bill amount is:

```text
Bill = $100
Tip = 15%
```

The tip would be:

```text
Tip = $15
```

And the final amount would be:

```text
Total = $115
```

The application performs these calculations dynamically based on the user's input.
